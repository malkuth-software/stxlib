Targets

    
Targets are the programs this appliance runs. Changes to
      their settings take effect at the next reboot; start, stop and restart
      act now.

    

    

      
Output

      
The newest output the target wrote (standard output and
        error), as the supervisor keeps it in memory: about 4 KiB.

      

      
      
    

    
Add a target

    

      
      
      
Required: role (server or foreground), id (1 to 999, never reused),
        command (a path inside the package) and folder (below /data/targets).
        Optional: program, ports, devices, restart, update-url, update-interval, healthy-after.
        Whether it starts at boot is the box below, not a setting.

      
      
      
    

  


  

    
Updates

    
Program package

    
Upload a signed program package; then install it from a
      target's entry on the Targets page.

    

      
      
    

    
System image

    
Upload a signed system image; it is written to the other
      root slot and tried at the next boot.
