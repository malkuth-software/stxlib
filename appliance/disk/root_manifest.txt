# (C1 step S4; C2), besides our own files (kernel, stx programs, /etc/stx,
# the accounts, the certificate bundle). build_image.sh (C2) and
# build_disk.sh (C1) copy each path and the shared libraries the programs
# need, so the root holds exactly what the failsafe path, normal running
# (Ethernet, sshd, the clock) and the targets' launcher use; check_root.sh
# then holds the built root to this list, every path. One path per line;
# # starts a comment. Accounts are generated (master.passwd, group in this
# directory, pwd_mkdb), not copied; build_disk.sh (C1 only) still copies
# the base's.
